PrintingTools NG 簡介

PrintingTools NG 提供多種電子郵件列印的自訂選項。 這個擴充套件可以調整標題與郵件內容的多種設定， 此外，也能設定一般 Thunderbird 預覽列印中無法修改的頁面選項。 你也可以透過強大的「自訂欄位命名系統」自動命名匯出的 PDF 檔案。

將 Print NG 按鈕加入郵件標題工具列：

自 Thunderbird 版本 115 起，Print NG 按鈕會自動加入工具列。 你也可以將此按鈕加入郵件標題工具列，以便在郵件視窗中快速存取列印功能與相關選項。 此外，透過附加元件分頁中的扳手圖示按鈕，也能開啟進階選項設定。


按照以下步驟將按鈕加入在郵件標題工具列上

  • 點擊郵件標題工具列上的「更多」按鈕
  • 選擇「自訂...」，這會開啟自訂工具列視窗
  • 找到「Print NG」按鈕
  • 將按鈕拖曳至你想放置的位置
  • 使用該按鈕可執行列印、預覽、選項與說明功能

    • 鍵盤快捷鍵說明

    PrintingTools 會重新指定 Thunderbird 原本的列印快捷鍵， 讓它啟動 PrintingTools 自身的列印功能，而不是使用內建的列印功能。 在 Windows 和 Linux 系統上，請使用 Ctrl + P，在 Mac 上則使用 Command + P。 此外，也可以使用 Ctrl + Shift + P 快捷鍵開啟選項設定視窗。

    以下是標題格式功能的範例：

  • 使用 CSS 自訂標題邊框樣式（上下邊框、藍色）
  • 標題背景顏色
  • 標題對齊
  • 自訂標題顯示順序
  • 頁面標題與郵件資料夾名稱
  • 標題中顯示附加檔案清單與圖示
  • 可完全自訂的國際化日期格式


    • 自訂日期格式

    自訂日期選項可讓你完全掌控電子郵件標題中「日期」與「接收日期」的格式。 你可以使用多種在地化格式，自由調整幾乎任何顯示樣式。 請注意，自訂日期字串中可以包含分隔符號、文字（包括 Unicode 字元），並與下方列出的日期／時間代碼混合使用。

    **注意：**以下範例中的自訂日期結果，會根據實際日期、使用者的語系與時區而有所不同。


    範例：

    日期字串 結果 說明
    %Y%0%m%1%d%2 %a %t %H:%M:%S [GMT %z] 2022年04月20日 水 JST 16:06:45 [GMT +0900] ja 日文語系（含自訂文字）
    %Y%0%m%1%d%2 %a %t %H:%M:%S 2022년04월20일 수 KST 16:11:06 ko 韓國語系（含自訂文字）
    %Y%0%m%1%d%2 %a %H:%M:%S %Z 2022年04月20日 周三 18:01:42 北京时间 zh-CN 中國語系，精簡日期
    %Y%0%m%1%d%2 %A %H:%M:%S %t 2022年04月20日 星期三 18:01:42 CST zh-TW 台灣語系，完整日期
    %d.%m.%Y %H:%M:%S %t 20.04.2022 18:01:42 CET "."作為分割符號
    %a, %b %d %Y %H:%M:%S Mi, Apr 20 2022 18:01:42 de 德國語系，精簡日期(日/月)
    %A, %B %d %Y (%H:%M:%S) %t Wednesday, April 20 2022 (18:01:42) EDT en-US 美國(英文)語系，完整日期(日/月)

    自訂日期格式是透過 % 開頭來進行的，這些格式符號與 Unix 的strftime()函式的功能類似。它是基於 JavaScript 的strftime() 所開發，該函式可用來格式化日期與時間。
    這個 JavaScript 移植版本由 T. H. Doan 製作（https://thdoan.github.io/strftime/）


    格式轉換符號說明

    代碼 說明
    %a 星期幾的縮寫
    %A 星期幾的完整名稱
    %b 月份縮寫
    %B 月份完整名稱
    %c 目前語系偏好的日期與時間（UTC）格式
    %C 世紀數（年份除以 100），以兩位數表示
    %d 月份中的日期（十進位，範圍 01 到 31）
    %e 月份中的日期（十進位，範圍 1 到 31）
    %F ISO 8601 日期格式（相當於%Y-%m-%d ）。
    %G ISO 8601 以週為基準的年份（含世紀，四位數）。這個四位數的年份會對應到 ISO 週數（請參考 %V）。 其格式與數值通常與 %Y 相同， 但若該 ISO 週數屬於前一年或下一年，則會顯示對應的那一年的年份。
    %g 類似%G，但只顯示兩位數年份（00–99）
    %H 24 小時制的小時（00 到 23），另見%k
    %I 12 小時制的小時（01 到 12），另見%l
    %j 一年中的第幾天（001 到 366）
    %k 24 小時制的小時（0 到 23），另見 %H
    %l 12 小時制的小時（1 到 12），另見%I
    %m 月份（01 到 12）
    %n 月份（1 到 12）
    %M 分鐘（00 到 59）
    %p 時間值對應的 AM 或 PM，中午為 PM，午夜為 AM
    %P 類似%p，但為小寫（am 或 pm）
    %s 自 1970-01-01 00:00:00 UTC 起的秒數
    %S 秒數（00 到 59）
    %u 星期幾（1 到 7，星期一為 1），另見 %w
    %V ISO 週數（01 到 53，第一週為新年中有四天的週）
    %w 星期幾（0 到 6，星期日為 0），另見%u
    %x 目前語系偏好的日期格式（不含時間）
    %X 目前語系偏好的時間格式（不含日期）
    %y 年份（不含世紀，00 到 99）
    %Y 年份（含世紀）
    %z 數字時區偏移量(+hhmm或-hhmm)
    %Z 時區名稱或縮寫
    %t 時區縮寫（精簡）
    %0 年份文字，主要用於亞洲語系（zh-CN：年，ko：년）
    %1 月份文字，主要用於亞洲語系（zh-TW：月，ko：월）
    %2 日期文字，主要用於亞洲語系（ja：日，ko：일）

    相容性注意事項：

    • %c - 格式化的字串略有不同
    • %D - 尚未支援（請改用 %m/%d/%y 或 %d/%m/%y）
    • %e - 不會補上空格
    • %E - 尚未支援
    • %h - 尚未支援（請改用 %b）
    • %k - 不會補上空格
    • %n - 類似 %m，但不會補 0（若要換行請使用 \n）
    • %O - 尚未支援
    • %r - 尚未支援（請改用 %I:%M:%S %p）
    • %R - 尚未支援（請改用 %H:%M）
    • %t - 尚未支援（請改用 \t）
    • %T - 尚未支援（請改用 %H:%M:%S）
    • %U - 尚未支援
    • %W - 尚未支援
    • %+ - 尚未支援
    • %% - 尚未支援（請改用 %）

    PDF 匯出與自動檔名

    PDF 匯出現在可以透過「命名欄位標記系統」自動命名，並儲存到預先指定的 PDF 匯出資料夾。 這在一次列印多封郵件時特別實用，因為不需要每封郵件都手動選擇檔名與儲存位置。

    請啟用 PDF 匯出資料夾功能，並選擇一個儲存位置。匯出的檔名將依照你設定的格式自動產生。

    檔名格式由「命名欄位標記」與其他靜態字元（如分隔符號或空格）組成。 進階檔名格式可使用多種代碼組合、文字與有效的檔名字元構成完整的檔案名稱。 無效的檔名字元包含：| * : < > ? \ / "

    預設的檔名格式是：${subject}，也就是郵件的主旨。

    範例：

    ${subject} - 預設格式，郵件主旨
    ${prefix}_${date_custom}_${sender} - 使用自訂日期格式取代預設
    ${subject}-GmailMsg-${date}-${index} - 加上自訂文字的範例

    下方表格列出了可用於「檔名格式」中的所有命名欄位標記。

    命名欄位 說明
    ${subject} 郵件的主旨。
    ${sender} 寄件人的名稱。
    ${recipient} 收件人的名稱。
    ${sender_email} 寄件人的電子郵件地址。
    ${recipient_email} 收件人的電子郵件地址。
    ${smart_name} 如果郵件位於寄件備份匣，則為收件人名稱；否則為寄件人名稱。
    ${index} 郵件的索引編號。
    ${prefix} 前綴文字的選項值。
    ${suffix} 後綴文字的選項值。
    ${date} 標準日期格式。預設格式為：YYYYMMDDHHmm。
    ${date_custom} 自訂日期格式。請參閱自訂日期格式說明。

    列印與版面設定

    這些選項可讓你設定預設印表機，以及每台印表機專屬的版面配置。 你也可以啟用「快速列印模式」，直接列印而不顯示預覽畫面。

    版面設定適用於預覽列印或實際列印時。這些設定會在每次列印時保留。 如果你在列印預覽中變更了 PrintingTools NG 的設定，它們不會影響接下來的列印。 有些項目無法在預覽對話框中修改，例如頁首與頁尾； 也有些項目預覽不會保留，通常每次列印都要重新設定。 PrintingTools NG 解決了這兩種情況。

    一個無法在預覽中儲存的設定是「列印範圍」。 常見的情境是只想列印郵件的第一頁作為預設。 以往每次都要手動設定列印範圍。 注意：若你在 PrintingTools NG 中設定的頁碼範圍無效（例如超過頁數）， 那麼在列印前需要於預覽中修正。 如果設定為「1」，則永遠有效，會列印郵件的第一頁。

    備註：

    縮放選項允許你設定永久性的縮放比例。

    列印範圍的寫法與預覽畫面相同，例如：1、1-2、3-4,5。 若指定的範圍對某封郵件無效，預覽畫面會顯示錯誤。

    邊界單位可依照使用者地區選擇使用「英吋（in）」或「公釐（mm）」。 注意：由於四捨五入誤差，某些 mm 數值儲存時可能會有些微差距。

    你可以在頁首與頁尾中插入下列的郵件變數，或輸入自訂文字。 若你不想列印任何頁首／頁尾來節省紙張，只要將所有欄位留空即可。

  • &D = 日期
  • &P = 頁碼
  • &PT = 頁碼／總頁數（例如「3 / 5」）
  • &T = 頁面標題（郵件主旨）
  • &U = 網址（郵件的 URL）

    • 進階選項

    這些選項可讓你設定比基本介面更多的列印參數。目前的進階功能是用來控制頁首與頁尾的邊緣邊界（edge margins）。 這些設定位於「其他選項」頁籤中的「進階選項」，並以空白隔開各個條目。
    格式如下：

    P:印表機名稱::S:選項名稱=數值

    印表機名稱中的空格需改為底線， 內建的「儲存為 PDF」功能名稱為：Mozilla_Save_to_PDF

    另一個範例：Microsoft_Print_to_PDF

    目前可用的選項名稱包括：
    edges、edgeTop、edgeBottom、edgeLeft、edgeRight

    edges 是一種「虛擬選項」，可以一次設定四邊的邊界為相同的數值。 邊界的單位為英吋（in）。

    範例：

    P:Mozilla_Save_to_PDF::S:edges=0.25
    P:Microsoft_Print_to_PDF::S:edgeTop=0.1

    如果你希望除了 edgeTop 設定為 0.25 英吋，其餘邊界都設為 0.10 英吋，可輸入：

    P:Mozilla_Save_to_PDF::S:edges=0.10 P:Mozilla_Save_to_PDF::S:edgeTop=0.25

    除錯選項

    除錯選項是一組關鍵字，需以空格分隔輸入。 這些選項通常用於「除錯主控台（Debug Console）」輸出， 也可用於測試或開啟不同的模式。

  • initialsource - 顯示原始郵件內容（在 PTNG 格式化前）
  • finaloutput - 顯示最終輸出的郵件內容
  • pdfoutput - 顯示 PDF 輸出的除錯資訊
  • printsettings - 顯示列印與版面設定的除錯資訊
  • helpinwin - 將說明顯示在獨立視窗中（預設為分頁）

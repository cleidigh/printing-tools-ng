PrintingTools NG 개요

PrintingTools NG는 이메일 인쇄에 다양한 사용자 정의 기능을 제공합니다. 헤더와 메시지 부분 모두에 다양한 옵션을 제공합니다. 또한, 일반 Thunderbird 인쇄 미리보기에서는 설정할 수 없는 페이지 옵션도 설정할 수 있습니다. 유연한 토큰 기반 시스템을 사용하여 PDF 출력 시 자동 이름 지정 기능을 사용할 수도 있습니다.

메일 헤더 도구 모음에 인쇄 NG 버튼 추가:

Thunderbird v115부터 통합 도구 모음에 인쇄 NG 버튼이 자동으로 추가되었습니다. 이 버튼을 메일 헤더 도구 모음에 추가하여 인쇄 기능 및 메일 창에서 옵션을 활성화할 수도 있습니다. 또한, 애드온 탭에서 확장 프로그램의 렌치 버튼을 사용하여 옵션에 액세스할 수 있습니다.


메일 헤더 도구 모음에 버튼을 배치하려면 다음 단계를 따르세요.

  • 메일 헤더 도구 모음에서 더보기 버튼을 클릭하세요.
  • 사용자 정의를 선택하세요... 그러면 도구 모음 사용자 정의 창이 열립니다.
  • 인쇄 NG 버튼을 찾으세요
  • 원하는 위치로 버튼을 끌어다 놓으세요
  • 인쇄, 미리보기, 옵션 및 도움말 버튼을 사용하세요.

    • PrintingTools NG 키보드 단축키

    PrintingTools는 표준 Thunderbird 인쇄 단축키를 다시 매핑하여 표준 인쇄 대신 자체적으로 호출합니다. Windows 및 Linux에서는 Control-P, Mac에서는 Command-P를 사용합니다. Control-Shift-P를 사용하여 옵션 대화 상자를 열 수도 있습니다.

    다음은 일부 헤더 서식 기능의 예입니다.

  • CSS를 사용하여 사용자 정의 헤더 테두리 스타일(상단 및 하단, 파란색)
  • 헤더 배경색
  • 정렬된 헤더
  • 사용자 정의 헤더 순서
  • 페이지 제목 및 메시지 폴더
  • 헤더에 아이콘이 있는 첨부 파일 목록
  • 완벽하게 사용자 정의 가능한 날짜 형식 국제 형식


    • 사용자 정의 날짜 형식

    사용자 지정 날짜 옵션을 사용하면 이메일 헤더의 날짜 및 수신 날짜에 사용되는 날짜 형식을 완벽하게 제어할 수 있습니다. 사용자 지정 날짜는 거의 모든 형식을 허용하는 다양한 현지화된 옵션을 제공합니다. 사용자 지정 날짜 문자열에는 구분 기호, 유니코드 문자를 포함한 리터럴이 아래 나열된 날짜/시간 토큰과 함께 포함될 수 있습니다.

    참고: 아래 예시의 사용자 지정 날짜 결과는 실제 날짜, 사용자 로케일 및 시간대에 따라 달라집니다.


    예:

    날짜 문자열 결과 메모
    %Y%0%m%1%d%2 %a %t %H:%M:%S [GMT %z] 2022年04月20日 水 JST 16:06:45 [GMT +0900] 리터럴이 있는 ja 로케일
    %Y%0%m%1%d%2 %a %t %H:%M:%S 2022년04월20일 수 KST 16:11:06 리터럴을 사용한 ko 로케일
    %Y%0%m%1%d%2 %a %H:%M:%S %Z 2022年04月20日 周三 18:01:42 北京时间 zh-CN 로케일, 짧은 날
    %Y%0%m%1%d%2 %A %H:%M:%S %t 2022年04月20日 星期三 18:01:42 CST zh-TW 로케일, 긴 하루
    %d.%m.%Y %H:%M:%S %t 20.04.2022 18:01:42 CET 점 구분 기호
    %a, %b %d %Y %H:%M:%S Mi, Apr 20 2022 18:01:42 지역, 짧은 하루/한 달
    %A, %B %d %Y (%H:%M:%S) %t Wednesday, April 20 2022 (18:01:42) EDT en-US 로케일, 긴 하루/한 달

    사용자 지정 날짜 형식은 strftime() 유닉스 계열 함수와 일치하는 % 시퀀스를 사용합니다. 날짜와 시간을 형식화하는 함수인 strftime() JavaScript로 포팅한 것입니다.
    TH Doan이 만든 strftime() 포팅(https://thdoan.github.io/strftime/)


    변환 시퀀스 설명

    순서 설명
    %a 요일의 약어입니다.
    %A 요일의 전체 이름.
    %b 약어화된 월 이름.
    %B 전체 월 이름.
    %c 현재 로케일에 대한 기본 날짜 및 시간(UTC) 표현입니다.
    %C 세기 숫자(년/100)를 2자리 정수로 표현합니다.
    %d 매월의 날짜를 10진수로 나타냅니다(범위: 01~31).
    %e 매월의 날짜를 10진수로 나타냅니다(범위: 1~31).
    %F ISO 8601 날짜 형식( %Y-%m-%d 와 동일).
    %G ISO 8601 주 단위 연도(세기를 10진수로 표시). 4자리 연도는 ISO 주 번호에 해당합니다( %V 참조). %Y 와 형식과 값이 동일하지만, ISO 주 번호가 이전 또는 다음 연도에 속하는 경우 해당 연도가 대신 사용됩니다.
    %g %G 와 비슷하지만 세기가 없고, 2자리 연도(00-99)를 사용합니다.
    %H 24시간제(00~23)를 사용하여 시간을 10진수로 표현합니다. %k 도 참조하세요.
    %I 12시간제(01~12)를 사용하여 시간을 10진수로 표현합니다. %l 도 참조하세요.
    %j 10진수로 표현한 연중 날짜(범위: 001~366).
    %k 24시간제(0~23)를 사용하여 시간을 10진수로 표현합니다. %H 도 참조하세요.
    %l 12시간제(1~12)를 사용하여 시간을 10진수로 표현합니다. %I 도 참조하세요.
    %m 월을 10진수로 표현(범위: 01~12).
    %n 월을 10진수로 표현합니다(범위: 1~12).
    %M 분을 10진수로 표현합니다(범위: 00~59).
    %p 주어진 시간 값에 따라 "AM" 또는 "PM"으로 처리됩니다. 정오(12시)는 "PM"으로, 자정(12시)은 "AM"으로 처리됩니다.
    %P %p 와 유사하지만 소문자입니다("am" 또는 "pm").
    %s 1970년 1월 1일 00:00:00 +0000(UTC) 기준 초 수입니다.
    %S 초를 10진수로 표현(범위 00~59).
    %u 요일을 소수점 1~7로 표현한 값이며 월요일은 1입니다. %w 도 참조하세요.
    %V ISO 8601은 현재 연도의 주 번호를 10진수로 나타낸 값(범위 01~53)입니다. 여기서 주 1은 새해에 4일 이상 있는 첫 번째 주(즉, 첫 번째 목요일)입니다.
    %w 요일을 소수점 0~6으로 표현한 값이며, 일요일은 0입니다. %u 도 참조하세요.
    %x 시간을 제외한 현재 로케일에 대한 기본 날짜 표현입니다.
    %X 날짜를 제외한 현재 로케일의 기본 시간 표현입니다.
    %y 세기를 제외한 소수로 표현된 연도(범위: 00~99).
    %Y 세기를 포함한 10진수로 표현한 연도입니다.
    %z +hhmm 또는 -hhmm 숫자형 시간대(즉, UTC와의 시간 및 분 오프셋).
    %Z 시간대 이름 또는 약어.
    %t 짧은 시간대의 약어.
    %0 연도 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-CN: 年, ko: 년)
    %1 월 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-TW: 月, ko: 월)
    %2 일 리터럴. 주로 아시아 지역에 맞춰 현지화되었습니다. (ja: 일, ko: 일)

    호환성 참고 사항:

    • %c - 포맷된 문자열이 약간 다릅니다
    • %D - 구현되지 않음( %m/%d/%y 또는 %d/%m/%y 사용)
    • %e - 공백이 추가되지 않습니다
    • %E - 구현되지 않음
    • %h - 구현되지 않음( %b 사용)
    • %k - 공백이 추가되지 않습니다.
    • %n - %m 과 유사하지만 앞에 0이 없음(줄 바꿈에는 \n 사용)
    • %O - 구현되지 않음
    • %r - 구현되지 않음( %I:%M:%S %p 사용)
    • %R - 구현되지 않음( %H:%M 사용)
    • %t - 구현되지 않음( \t 사용)
    • %T - 구현되지 않음( %H:%M:%S 사용)
    • %U - 구현되지 않음
    • %W - 구현되지 않음
    • %+ - 구현되지 않음
    • %% - 구현되지 않음( % 사용)

    PDF 출력 및 자동 파일 이름 지정

    이제 PDF 출력 파일의 이름을 토큰 시스템을 사용하여 자동으로 지정하고 미리 정의된 PDF 출력 디렉터리에 저장할 수 있습니다. 이 기능은 여러 개의 이메일을 선택하여 인쇄할 때 특히 유용합니다. 각 이메일의 이름과 위치를 따로 지정할 필요가 없기 때문입니다.

    PDF 출력 디렉터리를 활성화하고 저장 위치를 선택하세요. 출력 파일 이름은 구성된 파일 이름 형식을 따릅니다.

    파일 이름 형식은 토큰과 구분 기호, 공백 등의 정적 문자로 구성됩니다. 확장 파일 이름 형식은 토큰을 활용합니다. 토큰과 텍스트 또는 유효한 파일 이름 문자를 사용하여 정확한 파일 이름을 생성할 수 있습니다. 유효하지 않은 문자는 다음과 같습니다. | * : < > ? \ / "

    기본 이름 형식은 ${subject}이며, 이는 이메일의 제목일 뿐입니다.

    예시

    ${subject} - 이메일의 기본 형식, 제목
    ${prefix}_${date_custom}_${sender} - 기본값 대신 사용자 지정 날짜 형식을 사용합니다.
    ${subject}-GmailMsg-${date}-${index} - 일부 사용자 정의 텍스트 포함

    아래 표에서는 파일 이름 형식에서 사용할 수 있는 전체 토큰 세트를 설명합니다.

    토큰 설명
    ${subject} 메시지의 제목.
    ${sender} 메시지 발신자의 이름입니다.
    ${recipient} 메시지 수신자의 이름입니다.
    ${sender_email} 메시지 발신자의 이메일 주소.
    ${recipient_email} 메시지 수신자의 이메일 주소.
    ${smart_name} 메시지가 보낸 편지함에 있는 경우 수신자, 그렇지 않은 경우 보낸 사람 이름
    ${index} 메시지 인덱스 번호.
    ${prefix} 접두사 텍스트 옵션 값입니다.
    ${suffix} 접미사 텍스트 옵션 값입니다.
    ${date} 표준 날짜 형식입니다. 기본 형식은 YYYYMMDDHHmm입니다.
    ${date_custom} 사용자 지정 날짜 형식입니다. 사용자 지정 날짜 형식 지정 섹션을 참조하세요.
    ${messageID} 이메일의 고유한 메시지 ID입니다.

    인쇄 및 페이지 옵션

    이 옵션을 사용하면 기본 프린터와 프린터 페이지 옵션을 설정할 수 있습니다. 또한, 미리 보기 대화 상자를 표시하지 않고 즉시 인쇄되는 무음 모드를 설정할 수도 있습니다.

    페이지 옵션을 사용하면 미리 보기 또는 인쇄 시 항목을 설정할 수 있습니다. 이러한 옵션은 인쇄 후에도 유지됩니다. PrintingTools NG에서 설정한 옵션을 인쇄 미리 보기에서 변경하더라도 이후 인쇄에는 영향을 미치지 않습니다. 머리글과 바닥글을 포함한 일부 항목은 미리 보기 대화 상자에서 설정할 수 없습니다. 다른 항목은 미리 보기에 유지되지 않으므로 일반적으로 인쇄할 때마다 설정해야 합니다. PrintingTools NG는 이 두 가지 문제를 모두 해결합니다.

    미리보기에서 저장되지 않는 항목 중 하나는 페이지 범위입니다. 일반적인 사용 사례는 이메일의 첫 페이지만 기본값으로 인쇄하려는 경우입니다. 일반적으로 페이지 범위는 매번 변경해야 합니다. PrintingTools NG에서 설정한 페이지 범위가 유효하지 않은 경우(예: 페이지 수 초과), 인쇄 전에 미리보기에서 범위를 수정해야 합니다. 페이지 범위를 "1"로 설정하면 항상 유효하며 메시지의 첫 페이지가 인쇄됩니다.

    참고사항:

    크기 조정 옵션을 사용하면 영구적인 크기 조정을 설정할 수 있습니다.

    페이지 범위는 미리보기와 동일한 방식으로 표시됩니다. 예를 들어 1, 1-2, 3-4, 5 등이 있습니다. 미리 설정된 페이지 범위가 해당 메시지에 유효하지 않으면 미리보기에 오류가 표시됩니다.

    여백은 사용자 로캘에 맞는 인치 또는 밀리미터(in 또는 mm) 단위를 사용하여 설정할 수 있습니다. 단, 반올림 오류로 인해 일부 mm 값은 미세한 차이로 저장될 수 있습니다.

    아래 나열된 다양한 메시지 변수를 포함하도록 머리글과 바닥글을 설정할 수 있습니다. 또한 임의의 텍스트를 포함할 수도 있습니다. 머리글이나 바닥글을 인쇄하지 않고 인쇄 공간을 절약하려면 모든 필드를 비워 두세요.

  • &D = 날짜 인쇄
  • &MD = 메시지 날짜
  • &P = 페이지 번호
  • &PT = 총 페이지 번호("5개 중 3개")
  • &T = 페이지 제목(메시지의 제목)
  • &U = URL (메시지의 URL)

    • 고급 옵션

    이 옵션을 사용하면 기본 UI 설정 외에 인쇄 항목을 설정할 수 있습니다. 이 옵션은 기타 탭의 고급 옵션에서 설정할 수 있으며, 공백으로 구분된 태그로 표시됩니다.
    옵션 태그와 형식은 아래와 같습니다.

    헤더 태그 끝에 Message-ID를 추가합니다.

    addMessageIdToHdr

    헤더 태그의 열 너비를 설정합니다.

    hdrColWidth: nnn 여기서 nnn 은 픽셀 수입니다.

    헤더 및 푸터 가장자리 여백:

    P: 프린터 이름 ::S: 옵션 이름 = 값

    프린터 이름의 공백은 밑줄로 바뀌었고 내장된 PDF 저장 기능은 Mozilla_Save_to_PDF입니다.

    또 다른 예: Microsoft_Print_to_PDF

    현재 옵션 이름의 가능성은 다음과 같습니다.
    edges, edgeTop, edgeBottom, edgeLeft, edgeRight

    edges 모든 가장자리 여백을 동일한 값으로 설정하는 가상 옵션입니다. 가장자리 여백은 인치 단위입니다.

    예:

    P:Mozilla_Save_to_PDF::S:가장자리=0.25
    P:Microsoft_Print_to_PDF::S:edgeTop=0.1

    edgeTop을 제외한 모든 가장자리 여백을 0.25인치로 설정하려면 다음을 입력합니다.

    P:Mozilla_Save_to_PDF::S:edges=0.10 P:Mozilla_Save_to_PDF::S:edgeTop=0.25

    지원하다

    문제나 기능 요청은 확장 GitHub 저장소인 PrintingTools NG Issues 에 게시해 주세요.

    버그 문제가 있는 경우, 다음 정보를 포함하면 문제를 해결하는 데 도움이 됩니다.
    - PrintingTools NG 버전
    - 썬더버드 버전
    - 운영체제 및 버전
    - 디버그 출력(디버그 콘솔에서 복사 - Control-Shift-J로 액세스)
    - 문제가 발생하는 단계에 대한 설명

    디버그 옵션

    디버그 옵션은 공백으로 구분된 목록 형태로 입력되는 키워드 집합입니다. 이 옵션은 일반적으로 콘솔 디버깅 출력에 사용되지만, 테스트 또는 다른 모드에도 사용될 수 있습니다.

  • initialsource - PTNG가 포맷을 하기 전에 메시지 소스를 표시합니다.
  • finaloutput - 최종 메시지 출력을 표시합니다.
  • pdfoutput - PDF 메시지 출력을 위한 디버그 출력
  • printsettings - 인쇄 및 페이지 옵션에 대한 디버그 출력
  • helpinwin - 탭의 표준 대신 창에 도움말을 표시하는 모드 플래그

PrintingTools NG 도움말
버전 2.2.1

릴리스 노트:

긴급: PDF 내보내기 또는 여러 메시지 인쇄 기능이 필요한 경우 Thunderbird 버전 147로 업데이트하지 마십시오.
Thunderbird에는 PDF 내보내기 또는 미리보기 없이 여러 메시지를 인쇄할 때 가끔씩 프로그램이 충돌하는 핵심 버그가 있습니다. 이 버그가 Thunderbird에서 언제 수정될지는 알 수 없습니다. 하지만 해당 버그를 보고했고 이미 검토 중이지만, 안타깝게도 Thunderbird v147에서는 수정될 가능성이 낮습니다.
향후 PrintingTools NG 업데이트를 ESR 채널에서만 진행할지 여부를 검토 중입니다. 앞으로 이러한 오류가 발생해서는 안 됩니다. 비공식 빌드를 사용해 봐야 할 수도 있는데, 아직 확실하지 않습니다. PrintingTools NG가 필요하신 경우, ESR 채널을 유지하시거나 ESR 채널로 롤백하여 연속성을 확보하셔야 합니다. 롤백 방법은 곧 GitHub 이슈 섹션에 게시할 예정입니다.

죄송하지만 이건 제가 어떻게 할 수 있는 일이 아닙니다.

크리스토퍼


PrintingTools NG 개요

PrintingTools NG는 이메일 인쇄를 위한 다양한 사용자 지정 옵션을 제공합니다. 이 확장 프로그램은 헤더와 본문 내용 모두에 대해 여러 가지 설정을 제공하며, 일반 Thunderbird 인쇄 미리보기에서는 불가능한 페이지 옵션 설정도 가능합니다. 또한, 유연한 토큰 기반 시스템을 사용하여 자동 이름 지정 기능을 통해 PDF 출력도 할 수 있습니다.

메일 헤더 툴바에 "Print NG" 버튼 추가:

Thunderbird v115부터 'Print NG' 버튼이 통합 도구 모음에 자동으로 추가됩니다. 이 버튼을 메일 헤더 도구 모음에도 추가하여 메일 창에서 인쇄 및 옵션에 접근할 수 있습니다. 또한, 확장 프로그램 탭의 렌치 모양 버튼을 통해서도 옵션에 접근할 수 있습니다.


메일 헤더 툴바에 버튼을 추가하려면 다음 단계를 따르세요.

  • 메일 헤더 도구 모음에서 더보기 버튼을 클릭하세요.
  • '사용자 지정'을 선택하면 도구 모음 사용자 지정 창이 열립니다.
  • Print NG 버튼을 찾으세요
  • 버튼을 원하는 위치로 드래그 앤 드롭하세요.
  • 인쇄, 미리 보기, 옵션 및 도움말을 보려면 버튼을 사용하세요.

    • PrintingTools NG 키보드 단축키

    PrintingTools는 Thunderbird의 기본 인쇄 바로가기 키를 기본 인쇄 기능 대신 자체를 실행하도록 재설정합니다. Windows 및 Linux에서는 Control-P, Mac에서는 Command-P를 사용하십시오. Control-Shift-P를 눌러 옵션 대화 상자를 열 수도 있습니다.

    다음은 헤더 서식 지정 기능의 예입니다.

  • CSS를 사용하여 헤더 테두리 스타일 사용자 지정(상단 및 하단, 파란색)
  • 헤더 배경색
  • 정렬된 헤더
  • 맞춤형 헤더 주문
  • 페이지 제목 및 메시지 폴더
  • 헤더에 아이콘이 포함된 첨부 파일 목록
  • 완벽하게 사용자 정의 가능한 날짜 형식 (국제 형식 지원)


    • 사용자 지정 날짜 형식

    사용자 지정 날짜 옵션을 사용하면 이메일 헤더의 날짜 및 수신 날짜에 사용되는 날짜 형식을 완벽하게 제어할 수 있습니다. 사용자 지정 날짜는 다양한 지역화 옵션을 제공하여 거의 모든 형식을 지원합니다. 사용자 지정 날짜 문자열에는 구분 기호, 유니코드 문자를 포함한 리터럴과 아래에 나열된 날짜/시간 토큰을 혼합하여 사용할 수 있습니다.

    참고: 아래 예시에서 사용자 지정 날짜를 입력하면 실제 날짜, 사용자의 지역 설정 및 시간대에 따라 결과가 달라질 수 있습니다.


    예시:

    날짜 문자열 결과 메모
    %Y%0%m%1%d%2 %a %t %H:%M:%S [GMT %z] 2022年04月20日 水 JST 16:06:45 [GMT +0900] ja 로케일(리터럴 포함)
    %Y%0%m%1%d%2 %a %t %H:%M:%S 2022년04월20일 수 KST 16:11:06 ko 로케일(문자열 포함)
    %Y%0%m%1%d%2 %a %H:%M:%S %Z 2022年04月20日 周三 18:01:42 北京时间 zh-CN 지역, 짧은 낮
    %Y%0%m%1%d%2 %A %H:%M:%S %t 2022年04月20日 星期三 18:01:42 CST zh-TW 지역, 긴 하루
    %d.%m.%Y %H:%M:%S %t 20.04.2022 18:01:42 CET 점 구분 기호
    %a, %b %d %Y %H:%M:%S Mi, Apr 20 2022 18:01:42 현지, 짧은 일/월
    %A, %B %d %Y (%H:%M:%S) %t Wednesday, April 20 2022 (18:01:42) EDT en-US 지역, 긴 하루/월

    사용자 지정 날짜 형식은 Unix의 strftime() 함수와 유사한 기능을 하는 % 시퀀스를 사용합니다. 이는 날짜와 시간을 형식화하는 함수인 strftime() 의 JavaScript 포트를 기반으로 합니다.
    TH Doan이 작성한 strftime() 함수(https://thdoan.github.io/strftime/)를 포팅했습니다.


    변환 순서 설명

    순서 설명
    %a 요일의 약칭.
    %A 요일의 정식 명칭.
    %b 월 이름의 약자.
    %B 월 이름 전체를 쓰세요.
    %c 현재 로케일에 대한 기본 날짜 및 시간(UTC) 표시 방식입니다.
    %C 세기를 나타내는 숫자(년/100)를 두 자리 정수로 표현합니다.
    %d 월의 일(소수점 표기, 범위: 1~31).
    %e 해당 월의 일수를 소수점 이하 자릿수(1~31)로 입력하세요.
    %F ISO 8601 날짜 형식( %Y-%m-%d 와 동일).
    %G ISO 8601은 세기를 십진수로 나타내는 주 단위 연도 표기법입니다. 4자리 연도는 ISO 주 번호에 해당합니다( %V 참조). 이는 %Y 와 동일한 형식과 값을 가지지만, ISO 주 번호가 이전 연도 또는 다음 연도에 해당하는 경우 해당 연도가 사용됩니다.
    %g %G 와 비슷하지만 세기가 없고, 즉 두 자리 연도(00-99)를 사용합니다.
    %H 24시간제를 사용하여 시간을 소수로 나타냅니다(범위: 00~23). %k 도 참조하십시오.
    %I 12시간제를 사용하여 시간을 소수로 나타냅니다(범위: 01~12). %l 도 참조하십시오.
    %j 연중 일수를 십진수(001~366)로 나타낸 숫자입니다.
    %k 24시간제를 사용하여 시간을 소수로 나타낸 값(범위 0~23). %H 도 참조하십시오.
    %l 시간은 12시간제를 사용하는 소수점 숫자(범위 1~12)로 표시됩니다. %I 도 참조하십시오.
    %m 월을 소수점 숫자(01~12)로 입력합니다.
    %n 월을 소수점 이하 자릿수(1~12)로 입력하십시오.
    %M 분을 소수점 이하 자릿수(00~59)로 나타냅니다.
    %p 주어진 시간 값에 따라 "AM" 또는 "PM"으로 표시됩니다. 정오는 "PM"으로, 자정은 "AM"으로 처리됩니다.
    %P %p 와 같지만 소문자입니다("am" 또는 "pm").
    %s 1970년 1월 1일 00시 00분 00초(UTC) 이후 경과된 초 수.
    %S 두 번째 값은 소수점 이하 자릿수(00~59)로 표시됩니다.
    %u 요일을 소수점(1~7)으로 나타내며, 월요일이 1입니다. %w 도 참조하십시오.
    %V ISO 8601에 따른 당해 연도의 주 번호는 10진수(범위 01~53)로 표시되며, 1주는 새해에 최소 4일 이상인 첫 번째 주(즉, 첫 번째 목요일)입니다.
    %w 요일을 소수점(0~6)으로 나타낸 값이며, 일요일은 0입니다. %u 도 참조하십시오.
    %x 현재 지역에서 시간을 제외한 선호하는 날짜 표시 방식입니다.
    %X 현재 위치에서 날짜를 제외한 선호하는 시간 표시 방식입니다.
    %y 연도를 세기를 제외한 소수점 이하 숫자로 표시합니다(범위: 00~99).
    %Y 세기를 포함한 소수점 이하 숫자로 연도를 표기합니다.
    %z +hhmm 또는 -hhmm 숫자 시간대(즉, UTC와의 시분 차이).
    %Z 시간대 이름 또는 약어.
    %t 시간대 약어.
    %0 연도 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-CN: 年, ko: 년)
    %1 월 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-TW: 月, ko: 월)
    %2 일(Day)을 문자 그대로 표기합니다. 주로 아시아 지역에 맞춰 현지화되었습니다. (일본어: 日, 한국어: 日)

    호환성 관련 참고 사항:

    • %c - 형식화된 문자열이 약간 다릅니다.
    • %D - 구현되지 않음 ( %m/%d/%y 또는 %d/%m/%y 를 사용하세요)
    • %e - 공백이 추가되지 않습니다.
    • %E - 구현되지 않음
    • %h - 구현되지 않음 ( %b 사용)
    • %k - 공백이 추가되지 않습니다.
    • %n - %m 과 비슷하지만 앞에 0이 붙지 않습니다 (줄 바꿈에는 \n 사용하세요).
    • %O - 구현되지 않음
    • %r - 구현되지 않음 ( %I:%M:%S %p 사용)
    • %R - 구현되지 않음 ( %H:%M 사용)
    • %t - 구현되지 않음 ( \t 사용)
    • %T - 구현되지 않음 ( %H:%M:%S 사용)
    • %U - 구현되지 않음
    • %W - 구현되지 않음
    • %+ - 구현되지 않음
    • %% - 구현되지 않음 ( % 사용)

    PDF 출력 및 자동 파일 이름 지정

    이제 토큰 시스템을 사용하여 PDF 출력 파일의 이름을 자동으로 지정할 수 있으며, 미리 정의된 PDF 출력 디렉터리에 저장할 수도 있습니다. 이는 여러 이메일을 선택하여 인쇄할 때 각 이메일마다 이름과 저장 위치를 지정할 필요가 없어 특히 유용합니다.

    PDF 출력 디렉토리를 활성화하고 저장 위치를 선택하세요. 출력 파일 이름은 설정한 파일 이름 형식을 따릅니다.

    파일 이름 형식은 토큰과 구분 기호 또는 공백과 같은 고정 문자로 구성됩니다. 확장 파일 이름 형식은 토큰을 사용합니다. 정확한 파일 이름은 토큰과 텍스트 또는 유효한 파일 이름 문자를 사용하여 구성할 수 있습니다. 유효하지 않은 문자는 다음과 같습니다. | * : < > ? \ / "

    기본 이름 형식은 ${subject}이며, 이는 이메일 제목입니다.

    예시

    ${subject} - 이메일의 기본 제목 형식입니다.
    ${prefix}_${date_custom}_${sender} - 기본 날짜 형식 대신 사용자 지정 날짜 형식을 사용합니다.
    ${subject}-GmailMsg-${date}-${index} - 일부 사용자 지정 텍스트 포함

    아래 표는 파일 이름 형식에 사용할 수 있는 모든 토큰을 설명합니다.

    토큰 설명
    ${subject} 메시지의 제목.
    ${sender} 메시지 발신자의 이름.
    ${recipient} 메시지 수신자의 이름.
    ${sender_email} 메시지 발신자의 이메일 주소입니다.
    ${recipient_email} 메시지 수신자의 이메일 주소.
    ${smart_name} 메시지가 보낸 편지함에 있으면 수신자 이름이 표시되고, 그렇지 않으면 발신자 이름이 표시됩니다.
    ${index} 메시지 인덱스 번호입니다.
    ${prefix} 접두사 텍스트 옵션 값입니다.
    ${suffix} 접미사 텍스트 옵션 값입니다.
    ${date} 표준 날짜 형식입니다. 기본 형식은 YYYYMMDDHHmm입니다.
    ${date_custom} 사용자 지정 날짜 형식입니다. 사용자 지정 날짜 형식 섹션을 참조하세요.
    ${messageID} 이메일의 고유 메시지 ID입니다.

    인쇄 및 페이지 옵션

    이러한 옵션을 사용하면 기본 프린터와 프린터별 페이지 옵션을 설정할 수 있습니다. 또한 미리 보기 대화 상자가 표시되지 않고 즉시 인쇄되는 무음 모드도 설정할 수 있습니다.

    페이지 옵션을 사용하면 미리 보기 또는 인쇄 시 항목을 설정할 수 있습니다. 이러한 옵션은 인쇄 후에도 유지됩니다. PrintingTools NG에서 설정한 옵션을 인쇄 미리 보기에서 변경하더라도 이후 인쇄에는 영향을 미치지 않습니다. 머리글과 바닥글과 같은 일부 항목은 미리 보기 대화 상자에서 설정할 수 없습니다. 또한 일부 항목은 미리 보기에 저장되지 않으므로 일반적으로 인쇄할 때마다 설정해야 합니다. PrintingTools NG는 이러한 두 가지 문제를 모두 해결합니다.

    미리보기에서 저장되지 않는 항목 중 하나는 페이지 범위입니다. 일반적인 사용 사례는 이메일의 첫 페이지만 기본적으로 인쇄하려는 경우입니다. 보통은 매번 페이지 범위를 변경해야 합니다. PrintingTools NG에서 설정한 페이지 범위가 페이지 수를 초과하는 등 유효하지 않은 경우, 인쇄하기 전에 미리보기에서 범위를 수정해야 합니다. 페이지 범위를 "1"로 설정하면 항상 유효하며 메시지의 첫 페이지가 인쇄됩니다.

    참고:

    확대/축소 옵션을 사용하면 고정된 크기를 설정할 수 있습니다.

    페이지 범위는 미리보기에서와 같은 방식으로 설명됩니다. 예: 1, 1-2, 3-4, 5. 미리 설정된 페이지 범위가 특정 메시지에 유효하지 않은 경우 미리보기에 오류가 표시됩니다.

    여백은 사용자의 지역 설정에 맞는 단위(인치 또는 밀리미터)로 설정할 수 있습니다. 단, 반올림 오차로 인해 일부 밀리미터 값은 약간의 차이가 발생할 수 있습니다.

    머리글과 바닥글에는 아래에 나열된 다양한 메시지 변수를 포함하도록 설정할 수 있습니다. 또한 임의의 텍스트를 포함할 수도 있습니다. 머리글과 바닥글을 인쇄하지 않고 인쇄 공간을 절약하려면 모든 필드를 비워 두십시오.

  • &D = 인쇄 날짜
  • &MD = 메시지 날짜
  • &P = 페이지 번호
  • &PT = 총 페이지 수("5개 중 3개")
  • &T = 페이지 제목 (메시지의 주제)
  • &U = URL (메시지의 URL)

    • 고급 옵션

    이러한 옵션을 사용하면 기본 UI 설정 외에 인쇄 항목을 세부적으로 설정할 수 있습니다. 옵션은 '기타' 탭의 '고급 옵션'에서 설정할 수 있으며, 공백으로 구분된 태그입니다.
    옵션 태그 및 형식은 다음과 같습니다.

    `headers` 태그 끝에 메시지 ID를 추가하세요.

    addMessageIdToHdr

    헤더 태그의 열 너비를 설정합니다.

    hdrColWidth: nnn ( 여기서 nnn 은 픽셀 수입니다.)

    머리글 및 바닥글 여백:

    P: 프린터 이름 ::S: 옵션 이름 = 값

    프린터 이름의 공백은 밑줄로 바뀌었고, 내장된 PDF 저장 기능은 Mozilla_Save_to_PDF입니다.

    또 다른 예: Microsoft_Print_to_PDF

    현재 가능한 옵션 이름은 다음과 같습니다.
    edges, edgeTop, edgeBottom, edgeLeft, edgeRight

    edges 는 모든 모서리 여백을 동일한 값으로 설정하는 가상 옵션입니다. 모서리 여백의 단위는 인치입니다.

    예시:

    P:Mozilla_Save_to_PDF::S:edges=0.25
    P:Microsoft_Print_to_PDF::S:edgeTop=0.1

    모든 여백을 0.10인치로 설정하고 상단 여백만 0.25인치로 설정하려면 다음과 같이 입력하십시오.

    P:Mozilla_Save_to_PDF::S:edges=0.10 P:Mozilla_Save_to_PDF::S:edgeTop=0.25

    지원하다

    문제 또는 기능 요청 사항은 확장 프로그램의 GitHub 저장소( PrintingTools NG Issues) 에 게시해 주세요.

    버그 문제를 신고할 때는 문제 해결에 도움이 될 수 있도록 다음 정보를 포함해 주세요.
    - PrintingTools NG 버전
    - 썬더버드 버전
    - 운영 체제 및 버전
    - 디버그 출력 (디버그 콘솔에서 복사 - Ctrl+Shift+J로 접근)
    - 문제 발생에 이르게 된 단계에 대한 설명

    디버그 옵션

    디버그 옵션은 공백으로 구분된 키워드 목록입니다. 이러한 옵션은 일반적으로 콘솔 디버깅 출력에 사용되지만 테스트 또는 다른 모드에도 사용할 수 있습니다.

  • initialsource - PTNG가 서식을 지정하기 전에 메시지 소스를 표시합니다.
  • finaloutput - 최종 메시지 출력을 표시합니다.
  • pdfoutput - PDF 메시지 출력에 대한 디버그 출력
  • printsettings - 인쇄 및 페이지 옵션에 대한 디버그 출력
  • helpinwin - 도움말을 탭 대신 창에 표시할지 여부를 결정하는 모드 플래그입니다.

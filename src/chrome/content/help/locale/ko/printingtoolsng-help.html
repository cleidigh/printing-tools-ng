PrintingTools NG 개요

PrintingTools NG는 이메일 인쇄에 대한 많은 사용자 정의를 허용합니다. 이 확장 프로그램은 헤더와 메시지 부분 모두에 대한 많은 옵션을 제공합니다. 또한 일반 Thunderbird 인쇄 미리보기에서 할 수 없는 페이지 옵션을 설정할 수 있습니다. PDF 출력은 유연한 토큰 기반 시스템을 사용하여 자동 명명으로 수행할 수도 있습니다.

메일 헤더 도구 모음에 인쇄 NG 버튼 추가:

Print NG 버튼은 Thunderbird v115부터 통합 툴바에 자동으로 추가되었습니다. 이 버튼은 메일 헤더 툴바에 추가되어 인쇄 액세스와 메일 패널의 옵션을 모두 활성화할 수도 있습니다. 또한 애드온 탭의 확장 프로그램에 대한 렌치 버튼을 통해 옵션에 액세스할 수 있습니다.


메일 헤더 도구 모음에 버튼을 배치하려면 다음 단계를 따르세요.

  • 메일 헤더 도구 모음에서 더 보기 버튼을 클릭하세요.
  • 사용자 정의를 선택하세요... 그러면 도구 모음 사용자 정의 창이 열립니다.
  • 인쇄 NG 버튼을 찾으세요
  • 원하는 위치로 버튼을 끌어다 놓으세요.
  • 인쇄, 미리보기, 옵션 및 도움말 버튼을 사용하세요.

    • PrintingTools NG 키보드 단축키

    PrintingTools는 표준 Thunderbird Print 단축키를 다시 매핑하여 표준 Print 대신 자체를 호출합니다. Windows 및 Linux에서는 Control-P를 사용하고 Mac에서는 Command-P를 사용합니다. Control-Shift-P로 옵션 대화 상자를 열 수도 있습니다.

    다음은 헤더 서식 기능 중 일부의 예입니다.

  • CSS를 사용한 사용자 지정 헤더 테두리 스타일(상단 및 하단, 파란색)
  • 헤더 배경색
  • 정렬된 헤더
  • 사용자 정의 헤더 순서
  • 페이지 제목 및 메시지 폴더
  • 헤더에 아이콘이 있는 첨부 파일 목록
  • 완벽하게 사용자 정의 가능한 날짜 형식 국제 형식


    • 사용자 정의 날짜 형식

    사용자 지정 날짜 옵션을 사용하면 이메일 헤더의 날짜와 수신 날짜에 사용되는 날짜 형식을 완벽하게 제어할 수 있습니다. 사용자 지정 날짜는 거의 모든 형식을 허용하는 여러 현지화된 옵션을 제공합니다. 사용자 지정 날짜 문자열에는 구분 기호, 리터럴(유니코드 문자 포함)이 아래에 나열된 date\time 토큰과 혼합될 수 있습니다.

    참고: 아래 예시의 사용자 지정 날짜 결과는 실제 날짜, 사용자 로케일 및 시간대에 따라 달라집니다.


    예시:

    날짜 문자열 결과 메모
    %Y%0%m%1%d%2 %a %t %H:%M:%S [GMT %z] 2022年04月20日 水 JST 16:06:45 [GMT +0900] ja 로케일과 리터럴
    %Y%0%m%1%d%2 %a %t %H:%M:%S 2022년04월20일 수 KST 16:11:06 리터럴을 사용한 ko 로케일
    %Y%0%m%1%d%2 %a %H:%M:%S %Z 2022年04月20日 周三 18:01:42 北京时间 zh-CN 로케일, 짧은 날
    %Y%0%m%1%d%2 %A %H:%M:%S %t 2022年04月20日 星期三 18:01:42 CST zh-TW 로케일, 긴 하루
    %d.%m.%Y %H:%M:%S %t 20.04.2022 18:01:42 CET 점 구분 기호
    %a, %b %d %Y %H:%M:%S Mi, Apr 20 2022 18:01:42 de locale, 짧은 하루/한 달
    %A, %B %d %Y (%H:%M:%S) %t Wednesday, April 20 2022 (18:01:42) EDT en-US 로케일, 긴 하루/한 달

    사용자 지정 날짜 형식은 strftime() Unix 유사 기능과 일치하는 % 시퀀스를 활용합니다. 날짜와 시간을 포맷하는 함수인 strftime() 의 JavaScript 포트를 기반으로 합니다.
    TH Doan이 만든 strftime() 포팅(https://thdoan.github.io/strftime/)


    변환 순서 설명

    순서 설명
    %a 요일의 약칭입니다.
    %A 요일의 전체 이름입니다.
    %b 약어화된 월 이름.
    %B 전체 월 이름.
    %c 현재 로케일에 대한 기본 날짜 및 시간(UTC) 표현입니다.
    %C 세기 숫자(년/100)를 2자리 정수로 표현합니다.
    %d 해당 월의 날짜를 10진수로 표현합니다(범위: 01~31).
    %e 해당 월의 날짜를 10진수로 표현합니다(범위: 1~31).
    %F ISO 8601 날짜 형식( %Y-%m-%d 와 동일).
    %G 세기를 10진수로 사용한 ISO 8601 주 기반 연도. 4자리 연도는 ISO 주 번호에 해당합니다( %V 참조). 이것은 %Y 와 동일한 형식과 값을 갖지만 ISO 주 번호가 이전 또는 다음 해에 속하는 경우 해당 연도가 대신 사용됩니다.
    %g %G 와 비슷하지만 세기가 없고, 2자리 연도(00-99)를 사용합니다.
    %H 24시간제(범위 00~23)를 사용한 10진수 형태의 시간. %k 도 참조하세요.
    %I 12시간제(범위 01~12)를 사용하여 10진수로 나타낸 시간입니다. %l 도 참조하세요.
    %j 일년 중 날짜를 10진수로 표현합니다(범위: 001~366).
    %k 24시간제(범위 0~23)를 사용한 10진수 형태의 시간. %H 도 참조하세요.
    %l 12시간제 시계를 사용한 10진수 형태의 시간(범위 1~12). %I 도 참조하세요.
    %m 10진수로 표현한 월(범위: 01~12).
    %n 10진수로 표현한 월(범위: 1~12).
    %M 분을 10진수로 표현(범위: 00~59).
    %p 주어진 시간 값에 따라 "AM" 또는 "PM". 정오는 "PM"으로, 자정은 "AM"으로 처리됩니다.
    %P %p 와 비슷하지만 소문자입니다("am" 또는 "pm").
    %s 1970-01-01 00:00:00 +0000(UTC) 이후의 초 수입니다.
    %S 10진수로 표현한 초(범위: 00~59).
    %u 소수점 형태로 표현한 요일(범위 1~7), 월요일은 1입니다. %w 도 참조하세요.
    %V ISO 8601은 현재 연도의 주 번호를 10진수(범위 01~53)로 표현합니다. 여기서 주 1은 새해에 4일 이상 있는 첫 번째 주(즉, 첫 번째 목요일)입니다.
    %w 소수점 형태로 표현한 요일(범위 0~6), 일요일은 0입니다. %u 도 참조하세요.
    %x 시간을 제외한 현재 로케일에 대한 기본 날짜 표현입니다.
    %X 날짜를 제외한 현재 로케일에 대한 기본 시간 표현입니다.
    %y 세기 없는 10진수로 표현한 연도(범위: 00~99).
    %Y 세기를 포함한 10진수로 표현한 연도입니다.
    %z +hhmm 또는 -hhmm 숫자형 시간대(즉, UTC와의 시간 및 분 오프셋).
    %Z 시간대 이름 또는 약어.
    %t 짧은 시간대의 약어입니다.
    %0 연도 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-CN: 年, ko: 년)
    %1 월 리터럴. 주로 아시아 지역에 맞게 현지화되었습니다. (zh-TW: 月, ko: 월)
    %2 Day Literal. 주로 아시아 로케일에 맞춰 지역화됨. (ja: 日, ko: 일)

    호환성 참고 사항:

    • %c - 포맷된 문자열이 약간 다릅니다
    • %D - 구현되지 않음( %m/%d/%y 또는 %d/%m/%y 사용)
    • %e - 공백이 추가되지 않습니다.
    • %E - 구현되지 않음
    • %h - 구현되지 않음( %b 사용)
    • %k - 공백이 추가되지 않습니다.
    • %n - %m 과 유사하지만 앞에 0이 없음(줄바꿈에는 \n 사용)
    • %O - 구현되지 않음
    • %r - 구현되지 않음( %I:%M:%S %p 사용)
    • %R - 구현되지 않음( %H:%M 사용)
    • %t - 구현되지 않음( \t 사용)
    • %T - 구현되지 않음( %H:%M:%S 사용)
    • %U - 구현되지 않음
    • %W - 구현되지 않음
    • %+ - 구현되지 않음
    • %% - 구현되지 않음( % 사용)

    PDF 출력 및 자동 파일 이름 지정

    PDF 출력은 이제 토큰 시스템을 사용하여 자동으로 이름을 지정하고 미리 정의된 PDF 출력 디렉토리에 저장할 수 있습니다. 이는 각 이메일에 대한 이름과 위치를 선택할 필요가 없으므로 여러 개의 선택된 이메일을 인쇄할 때 특히 유용합니다.

    PDF 출력 디렉토리를 활성화하고 저장 위치에 대한 디렉토리를 선택합니다. 출력 파일 이름은 구성된 파일 이름 형식을 따릅니다.

    파일 이름 형식은 토큰과 구분 기호나 공백과 같은 정적 문자로 구성됩니다. 확장된 파일 이름 형식은 토큰을 활용합니다. 정확한 파일 이름은 토큰과 텍스트 또는 유효한 파일 이름 문자를 사용하여 구성할 수 있습니다. 유효하지 않은 문자는 다음과 같습니다. | * : < > ? \ / "

    기본 이름 형식은 ${subject}이며, 이는 이메일의 제목일 뿐입니다.

    예시

    ${subject} - 이메일의 기본 형식, 제목
    ${prefix}_${date_custom}_${sender} - 기본값 대신 사용자 지정 날짜 형식을 사용합니다.
    ${subject}-GmailMsg-${date}-${index} - 일부 사용자 지정 텍스트 포함

    아래 표는 파일 이름 형식에서 사용할 수 있는 전체 토큰 세트를 설명합니다.

    토큰 설명
    ${subject} 메시지의 제목.
    ${sender} 메시지 발신자의 이름.
    ${recipient} 메시지 수신자의 이름.
    ${sender_email} 메시지 발신자의 이메일 주소.
    ${recipient_email} 메시지 수신자의 이메일 주소.
    ${smart_name} 메시지가 보낸 편지함에 있는 경우 수신자, 그렇지 않은 경우 발신자 이름
    ${index} 메시지 인덱스 번호.
    ${prefix} 접두사 텍스트 옵션 값입니다.
    ${suffix} 접미사 텍스트 옵션 값입니다.
    ${date} 표준 날짜 형식입니다. 기본 형식은 YYYYMMDDHHmm입니다.
    ${date_custom} 사용자 지정 날짜 형식. 사용자 지정 날짜 형식 섹션을 참조하세요.
    ${messageID} 이메일의 고유한 메시지 ID입니다.

    인쇄 및 페이지 옵션

    이러한 옵션을 사용하면 기본 프린터와 프린터 페이지 옵션을 설정할 수 있습니다. 미리보기 대화 상자가 표시되지 않고 인쇄가 즉시 수행되는 무음 모드를 설정할 수도 있습니다.

    페이지 옵션을 사용하면 미리 보기 또는 인쇄가 모두 수행될 때 항목을 설정할 수 있습니다. 이러한 옵션은 인쇄에서 영구적입니다. PrintingTools NG에서 설정한 옵션이 인쇄 미리 보기에서 변경되더라도 후속 인쇄에는 영향을 미치지 않습니다. 미리 보기 대화 상자에서 설정할 수 없는 항목에는 머리글과 바닥글이 포함됩니다. 다른 항목은 미리 보기에서 유지되지 않으며 일반적으로 인쇄가 수행될 때마다 설정해야 합니다. PrintingTools NG는 이 두 가지 문제를 모두 해결합니다.

    미리보기에서 저장되지 않는 한 가지 항목은 페이지 범위입니다. 일반적인 사용 사례는 이메일의 첫 페이지만 기본값으로 인쇄하려는 경우입니다. 일반적으로 페이지 범위를 매번 변경해야 합니다. PrintingTools NG에서 설정한 페이지 범위가 유효하지 않은 경우(예: 페이지 수 초과) 인쇄하기 전에 미리보기에서 범위를 수정해야 합니다. "1"로 설정된 페이지 범위는 항상 유효하며 메시지의 첫 페이지를 인쇄합니다.

    참고사항:

    크기 조정 옵션을 사용하면 지속적인 크기 조정을 설정할 수 있습니다.

    페이지 범위는 미리보기와 같은 방식으로 설명됩니다. 예를 들어 1, 1-2, 3-4,5입니다. 사전 설정된 페이지 범위가 주어진 메시지에 유효하지 않으면 미리보기에 오류가 표시됩니다.

    여백은 사용자 로케일에 적합한 단위인 인치 또는 밀리미터(in 또는 mm)를 사용하여 설정할 수 있습니다. 참고로, 반올림 오류로 인해 일부 mm 값이 약간의 차이로 저장될 수 있습니다.

    헤더와 푸터는 아래에 나열된 다양한 메시지 변수를 포함하도록 설정할 수 있습니다. 또한 임의의 텍스트도 포함할 수 있습니다. 헤더나 푸터를 인쇄하지 않고 인쇄 공간을 절약하려면 모든 필드를 비워 두기만 하면 됩니다.

  • &D = 인쇄 날짜
  • &MD = 메시지 날짜
  • &P = 페이지 번호
  • &PT = 총 페이지 번호("3/5")
  • &T = 페이지 제목(메시지의 제목)
  • &U = URL (메시지의 URL)

    • 고급 옵션

    이러한 옵션은 기본 UI 설정을 넘어 인쇄 항목을 설정할 수 있게 해줍니다. 옵션은 Misc 탭의 Advanced 옵션에서 설정되며 공백으로 구분된 태그입니다.
    옵션 태그와 형식은 아래와 같습니다.

    헤더 태그 끝에 Message-ID를 추가합니다.

    addMessageIdToHdr

    헤더 태그에 대한 열 너비를 설정합니다.

    hdrColWidth: nnn 여기서 nnn 은 픽셀 수입니다.

    헤더 및 푸터 가장자리 여백:

    P: 프린터 이름 ::S: 옵션 이름 = 값

    프린터 이름의 공백은 밑줄로 바뀌었고 내장된 PDF로 저장 기능은 Mozilla_Save_to_PDF입니다.

    또 다른 예: Microsoft_Print_to_PDF

    현재 옵션 이름의 가능성은 다음과 같습니다.
    edges, edgeTop, edgeBottom, edgeLeft, edgeRight

    edges 모든 edge margins을 같은 값으로 설정하는 pseudo 옵션입니다. edge margins은 인치 단위입니다.

    예시:

    P:Mozilla_PDF로_저장::S:가장자리=0.25
    P:Microsoft_PDF로_인쇄::S:edgeTop=0.1

    모든 가장자리 여백을 0.10인치로 설정하고 edgeTop만 0.25인치로 설정하려면 다음을 입력합니다.

    P:Mozilla_PDF로_저장::S:가장자리=0.10 P:Mozilla_PDF로_저장::S:가장자리위쪽=0.25

    디버그 옵션

    디버그 옵션은 공백으로 구분된 목록으로 입력되는 키워드 세트입니다. 옵션은 일반적으로 콘솔 디버깅 출력에 사용되지만 테스트 또는 다른 모드에도 사용될 수 있습니다.

  • initialsource - PTNG가 포맷팅을 하기 전에 메시지 소스를 표시합니다.
  • finaloutput - 최종 메시지 출력을 보여줍니다
  • pdfoutput - PDF 메시지 출력을 위한 디버그 출력
  • printsettings - 인쇄 및 페이지 옵션에 대한 디버그 출력
  • helpinwin - 탭의 표준 대신 창에 도움말을 표시하는 모드 플래그

Översikt över PrintingTools NG

Med PrintingTools NG kan du anpassa utskrifter av e-post på många sätt. Tillägget har inställningar för både meddelandehuvuden och andra delar av meddelandet. Du kan också göra sidinställningar som saknas i Thunderbirds vanliga förhandsgranskning. Meddelanden kan även sparas som PDF-filer och namnges automatiskt med hjälp av ett flexibelt system med filnamnsvariabler.

Lägga till knappen Skriv ut NG i meddelandehuvudets verktygsfält:

Knappen Skriv ut NG läggs automatiskt till i det enhetliga verktygsfältet från och med Thunderbird v115. Du kan också lägga till knappen i meddelandehuvudets verktygsfält för att nå utskrift och inställningar direkt från meddelanderutan. Inställningarna kan även öppnas med tilläggets skiftnyckelknapp på tilläggsfliken.


Så här lägger du till knappen i meddelandehuvudets verktygsfält:

  • Klicka på knappen Mer i meddelandehuvudets verktygsfält
  • Välj Anpassa… för att öppna fönstret Anpassa verktygsfältet
  • Leta reda på knappen Skriv ut NG
  • Dra och släpp knappen till önskad plats
  • Använd knappen för att skriva ut, förhandsgranska och öppna inställningar och hjälp

    • Kortkommandon för PrintingTools NG

    PrintingTools NG tar över Thunderbirds vanliga kortkommando för utskrift så att det öppnar tilläggets utskriftsfunktion. Använd Ctrl+P i Windows och Linux eller Kommando+P på Mac. Du kan också öppna inställningarna med Ctrl+Skift+P.

    Exemplet nedan visar några av funktionerna för formatering av meddelandehuvuden:

  • Anpassad kantlinje runt meddelandehuvudet med CSS (blå, upptill och nedtill)
  • Bakgrundsfärg för meddelandehuvudet
  • Justerade huvudfält
  • Anpassad ordning på huvudfälten
  • Sidtitel och meddelandemapp
  • Bilagelista med ikoner i meddelandehuvudet
  • Helt anpassningsbart datumformat med stöd för olika språk och regioner


    • Anpassat datumformat

    Med ett anpassat datumformat kan du styra hur både datum och mottagningsdatum visas i meddelandehuvudet. Språkanpassade formatsekvenser gör att du kan skapa nästan vilket format som helst. Formatsträngen kan innehålla avgränsare och annan fast text, även Unicode-tecken, tillsammans med datum- och tidssekvenserna nedan.

    Obs! Resultaten i exemplen nedan varierar beroende på det faktiska datumet, användarens språkinställning och tidszon.


    Exempel:

    Datumsträng Resultat Anmärkning
    %Y%0%m%1%d%2 %a %t %H:%M:%S [GMT %z] 2022年04月20日 水 JST 16:06:45 [GMT +0900] Språkinställningen ja med datumtecken
    %Y%0%m%1%d%2 %a %t %H:%M:%S 2022년04월20일 수 KST 16:11:06 Språkinställningen ko med datumtecken
    %Y%0%m%1%d%2 %a %H:%M:%S %Z 2022年04月20日 周三 18:01:42 北京时间 Språkinställningen zh-CN, förkortat veckodagsnamn
    %Y%0%m%1%d%2 %A %H:%M:%S %t 2022年04月20日 星期三 18:01:42 CST Språkinställningen zh-TW, fullständigt veckodagsnamn
    %d.%m.%Y %H:%M:%S %t 20.04.2022 18:01:42 CET Punkter som avgränsare
    %a, %b %d %Y %H:%M:%S Mi, Apr 20 2022 18:01:42 Språkinställningen de, förkortade veckodags- och månadsnamn
    %A, %B %d %Y (%H:%M:%S) %t Wednesday, April 20 2022 (18:01:42) EDT Språkinställningen en-US, fullständiga veckodags- och månadsnamn

    Det anpassade datumformatet använder %-sekvenser som motsvarar dem i Unix-funktionen strftime(). Det bygger på en JavaScript-version av strftime(), en funktion för att formatera datum och tid.
    JavaScript-versionen av strftime() är skriven av T. H. Doan (https://thdoan.github.io/strftime/)


    Beskrivningar av formatsekvenser

    Sekvens Beskrivning
    %a Förkortat namn på veckodagen.
    %A Veckodagens fullständiga namn.
    %b Förkortat månadsnamn.
    %B Fullständigt månadsnamn.
    %c Datum och tid i UTC-format.
    %C Sekeltal (år/100) som ett tvåsiffrigt heltal.
    %d Dag i månaden som ett tal (intervall 01 till 31).
    %e Dag i månaden som ett tal (intervall 1 till 31).
    %F Datum i UTC enligt ISO 8601. Formatet motsvarar %Y-%m-%d, men använder UTC-datumet i stället för det lokala datumet.
    %G Veckobaserat årtal enligt ISO 8601 med fyra siffror. Årtalet hör till ISO-veckonumret (se %V). Formatet och värdet är desamma som för %Y, men om ISO-veckan hör till föregående eller nästa år används det året i stället.
    %g Som %G, men med ett tvåsiffrigt årtal utan århundrade (00–99).
    %H Timme enligt 24-timmarsklockan som ett tal (intervall 00 till 23). Se även %k.
    %I Timme enligt 12-timmarsklockan som ett tal (intervall 01 till 12). Se även %l.
    %j Dag på året som ett tal (intervall 001 till 366).
    %k Timme enligt 24-timmarsklockan som ett tal (intervall 0 till 23). Se även %H.
    %l Timme enligt 12-timmarsklockan som ett tal (intervall 1 till 12). Se även %I.
    %m Månad som ett tal (intervall 01 till 12).
    %n Månad som ett tal (intervall 1 till 12).
    %M Minut som ett tal (intervall 00 till 59).
    %p Antingen "AM" eller "PM" beroende på klockslaget. Klockan 12 på dagen räknas som "PM" och midnatt som "AM".
    %P Som %p men med gemener ("am" eller "pm").
    %s Antal sekunder sedan Unix-epoken, 1970-01-01 00:00:00 +0000 (UTC).
    %S Sekund som ett tal (intervall 00 till 59).
    %u Veckodag som ett tal (intervall 1 till 7), måndag är 1. Se även %w.
    %V Veckonummer enligt ISO 8601 som ett tal (intervall 01 till 53), där vecka 1 är den första veckan med minst 4 dagar på det nya året (det vill säga veckan som innehåller årets första torsdag).
    %w Veckodag som ett tal (intervall 0 till 6), söndag är 0. Se även %u.
    %x Datum enligt den aktuella språkinställningen, utan klockslag.
    %X Klockslag enligt den aktuella språkinställningen, utan datum.
    %y Årtal utan århundrade (intervall 00 till 99).
    %Y Årtal inklusive århundrade.
    %z Den numeriska tidszonen +hhmm eller -hhmm (det vill säga skillnaden i timmar och minuter från UTC).
    %Z Tidszonens namn eller förkortning.
    %t Förkortat tidszonsnamn.
    %0 Språkanpassat tecken efter årtalet, främst för asiatiska språk. (zh-CN: 年, ko: 년)
    %1 Språkanpassat tecken efter månaden, främst för asiatiska språk. (zh-TW: 月, ko: 월)
    %2 Språkanpassat tecken efter dagen, främst för asiatiska språk. (ja: 日, ko: 일)

    Kompatibilitetsinformation:

    • %c - datum och tid visas i UTC-format
    • %D - inte implementerad (använd %m/%d/%y eller %d/%m/%y)
    • %e - mellanslag läggs inte till
    • %E - inte implementerad
    • %h - inte implementerad (använd %b)
    • %k - mellanslag läggs inte till
    • %n - som %m, men utan inledande nolla (använd \n för radbrytning)
    • %O - inte implementerad
    • %r - inte implementerad (använd %I:%M:%S %p)
    • %R - inte implementerad (använd %H:%M)
    • %t - ger tidszonsförkortningen i stället för ett tabulatortecken (använd \t för tabulator)
    • %T - inte implementerad (använd %H:%M:%S)
    • %U - inte implementerad
    • %W - inte implementerad
    • %+ - inte implementerad
    • %% - inte implementerad (använd %)

    PDF-utdata och automatisk filnamngivning

    PDF-filer kan namnges automatiskt med hjälp av filnamnsvariabler och sparas i en förvald utdatamapp. Det är särskilt användbart när du skriver ut flera markerade e-postmeddelanden, eftersom du då slipper välja namn och plats för varje meddelande.

    Aktivera utdatamappen för PDF-filer och välj var filerna ska sparas. Filnamnen följer det inställda filnamnsformatet.

    Filnamnsformatet består av variabler och valfri fast text, till exempel avgränsare eller mellanslag. Genom att kombinera variablerna med text och andra giltiga filnamnstecken kan du anpassa filnamnet. Ogiltiga tecken är: | * : < > ? \ / "

    Standardformatet är ${subject}, vilket ger e-postmeddelandets ämne som filnamn.

    Exempel:

    ${subject} – Standardformatet: e-postmeddelandets ämne
    ${prefix}_${date_custom}_${sender} – Använder det anpassade datumformatet i stället för standardformatet
    ${subject}-GmailMsg-${date}-${index} – Innehåller även egen text

    Tabellen nedan beskriver alla variabler som kan användas i filnamnsformatet.

    Variabel Beskrivning
    ${subject} Meddelandets ämne.
    ${sender} Avsändarens namn.
    ${recipient} Mottagarens namn.
    ${sender_email} Avsändarens e-postadress.
    ${recipient_email} Mottagarens e-postadress.
    ${smart_name} Mottagarnas namn om meddelandet finns i en mapp för skickade meddelanden, annars avsändarens namn.
    ${index} Meddelandets indexnummer.
    ${prefix} Texten som angetts i inställningen Prefix.
    ${suffix} Texten som angetts i inställningen Suffix.
    ${date} Datum i standardformatet YYYYMMDDHHmm.
    ${date_custom} Datum i det anpassade formatet. Se avsnittet om anpassat datumformat.
    ${messageID} E-postmeddelandets unika Message-ID.

    Utskrifts- och sidinställningar

    Här kan du välja standardskrivare och ange sidinställningar för varje skrivare. Du kan också aktivera utskrift utan dialogruta. Då visas ingen förhandsgranskning och utskriften startar direkt.

    Sidinställningarna gäller både vid förhandsgranskning och utskrift och sparas mellan utskrifterna. Om du ändrar dem i förhandsgranskningen påverkar det inte efterföljande utskrifter. Vissa inställningar, till exempel sidhuvud och sidfot, går inte att ändra i förhandsgranskningen. Andra sparas inte där och måste normalt anges på nytt inför varje utskrift. PrintingTools NG löser båda dessa problem.

    Sidintervallet är en av de inställningar som inte sparas i förhandsgranskningen. Om du till exempel alltid vill skriva ut enbart den första sidan i varje e-postmeddelande måste du normalt ändra sidintervallet varje gång. Om intervallet som anges i PrintingTools NG är ogiltigt, till exempel om det omfattar fler sidor än meddelandet innehåller, måste du rätta det i förhandsgranskningen innan du skriver ut. Sidintervallet "1" är alltid giltigt och skriver ut meddelandets första sida.

    Observera:

    Skalningsinställningen låter dig ange en skala som sparas mellan utskrifterna.

    Sidintervall anges på samma sätt som i förhandsgranskningen, till exempel 1, 1-2 eller 3-4,5. Om ett förinställt sidintervall är ogiltigt för ett meddelande visas ett fel i förhandsgranskningen.

    Marginalerna kan anges i tum eller millimeter (in eller mm), beroende på språkinställningarna. På grund av avrundningsfel kan vissa millimetervärden ändras något när de sparas.

    Sidhuvud och sidfot kan innehålla meddelandevariablerna nedan och valfri egen text. Lämna alla fält tomma om du vill utelämna sidhuvud och sidfot och spara utrymme på sidan.

  • &D = Utskriftsdatum
  • &MD = Meddelandets datum
  • &P = Sidnummer
  • &PT = Sidnummer och totalt antal sidor ("3 av 5")
  • &T = Sidtitel (meddelandets ämne)
  • &U = URL (meddelandets URL)

    • Avancerade inställningar

    Här kan du ange utskriftsinställningar som saknas bland de vanliga inställningarna i gränssnittet. Ange nyckelorden i fältet Avancerade inställningar på fliken Allmänt, med mellanslag mellan dem.
    Nyckelorden och deras format beskrivs nedan:

    Lägg till Message-ID sist i meddelandehuvudet:

    addMessageIdToHdr

    Ange kolumnbredden för meddelandehuvudet:

    hdrColWidth:nnn där nnn är antalet pixlar

    Kantmarginaler för sidhuvud och sidfot:

    P:skrivarnamn::S:alternativnamn=värde

    Ersätt mellanslag i skrivarnamnet med understreck. Den inbyggda funktionen Spara som PDF har namnet Mozilla_Save_to_PDF.

    Ett annat exempel är Microsoft_Print_to_PDF.

    Följande alternativnamn kan användas:
    edges, edgeTop, edgeBottom, edgeLeft, edgeRight

    edges är ett samlingsalternativ som ställer in alla kantmarginaler på samma värde. Kantmarginalerna anges i tum.

    Exempel:

    P:Mozilla_Save_to_PDF::S:edges=0.25
    P:Microsoft_Print_to_PDF::S:edgeTop=0.1

    För att ställa in alla kantmarginaler på 0,10 tum men den övre marginalen (edgeTop) på 0,25 tum anger du:

    P:Mozilla_Save_to_PDF::S:edges=0.10 P:Mozilla_Save_to_PDF::S:edgeTop=0.25

    Support

    Rapportera problem och föreslå nya funktioner i tilläggets GitHub-arkiv: Ärenden för PrintingTools NG

    Ta med följande uppgifter i felrapporter för att underlätta felsökningen:
    - Version av PrintingTools NG
    - Version av Thunderbird
    - Operativsystem och version
    - Felsökningsutdata (kopiera från felkonsolen, som öppnas med Ctrl+Skift+J)
    - En beskrivning av stegen som ledde till problemet

    Felsökningsinställningar

    Felsökningsalternativen anges som nyckelord med mellanslag mellan dem. De används vanligtvis för att skriva felsökningsinformation till konsolen, men kan också användas för tester eller för att aktivera olika lägen.

  • initialsource – visa meddelandets källkod innan PrintingTools NG formaterar det
  • finaloutput – visa meddelandet efter formateringen
  • pdfoutput – visa felsökningsinformation när meddelanden skrivs ut till PDF
  • printsettings – visa felsökningsinformation om utskrifts- och sidinställningarna
  • helpinwin – visa hjälpen i ett fönster i stället för på en flik
